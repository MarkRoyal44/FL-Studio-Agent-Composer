Settings

Two minutes to your first beat

  1. Open FL Studio. The dot in the header turns green when FL is linked. If it stays gray: Options › MIDI settings, pick loopMIDI Port, set Controller type to Agent Composer, and enable it.
  2. Pick a brain in the Brain tab. Claude Code, Codex, DeepSeek, a free local model with Ollama, or your own. Its card says what's missing.
  3. Just ask. "Make it 140 BPM." "Write a dark trap melody in A minor." "What plugins am I using?" Type / for free instant commands like /play and /undo.
  4. Approve. Every change shows an Okay to do this? card first, and each one is a single undo in FL. Click YOLO up top to skip the cards; click it again to bring them back.
  5. Melodies land in the Notes tab as a .mid you drag into FL, or in the piano roll via Tools › Scripting › Agent Composer.
  6. Your plugins live in the VST Dock: flip presets, turn knobs, park favorites. The agent can turn the same knobs.
  7. Teach it you. Drop lyrics, notes or a style guide into the Mini Brain and it reads them before it answers.

Want it inside FL? Options › Manage plugins › Find installed plugins once, then Add › Agent Composer opens this chat in a plugin window. The standalone window docks inside FL too.
